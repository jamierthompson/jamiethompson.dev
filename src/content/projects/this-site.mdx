import { Sparkles } from "@lucide/astro";

Projects can be `.md` or `.mdx`. This one is MDX, which means it can import and
render components inline <Sparkles size={16} class="inline" /> alongside the
prose. Set `url` in the frontmatter and the page gets a link out to the live
thing.

It's built with Astro, styled with Tailwind, and the writing lives in
`src/content/`. See [[hello-world]] for how linking works.
