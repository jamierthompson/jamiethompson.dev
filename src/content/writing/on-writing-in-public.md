Long and short pieces share one collection; length is a property of the post,
not a place it has to be filed. Everything takes the same frontmatter, plus an
optional `updated` date.

## Why headings

Headings give a longer piece structure. Anything markdown supports — lists,
quotes, code — renders through the same typography.

> Writing in public is thinking with the door open.
